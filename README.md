# Avito Moderation Frontend

Тестовое задание для стажёра Frontend (осенняя волна 2025).  
Приложение предназначено для модерации объявлений: просмотр списка, детали объявления, выполнение модерации и просмотр статистики работы.


Быстрый запуск

1. Запустить backend (папка `tech-int3-server` из задания Авито)

```bash
cd tech-int3-server
npm install
npm run dev

Сервер будет доступен по адресу:
http://localhost:3001/api/v1

2. Запустить frontend
bash
npm install
npm run dev
Фронтенд будет доступен по адресу:
arduino
http://localhost:5173
Основные разделы приложения
/list — Список объявлений
карточки товаров (фото, цена, статус, приоритет)
поиск и фильтры
сортировка
пагинация
переход к подробной информации

/item/:id — Страница объявления
галерея изображений
описание и характеристики
информация о продавце
история модерации
действия модератора:
Одобрить
Отклонить (с указанием причины)
На доработку
горячие клавиши: A, D, ←, →

/stats — Статистика
количество проверенных объявлений
проценты одобрения / отклонения
среднее время проверки
графики активности (Recharts)
переключение периода: сегодня / 7 дней / 30 дней

Дополнительно
светлая / тёмная тема (сохранение в localStorage)
строгая архитектура: API → hooks → pages → components
TypeScript + React + Material UI + Axios + Recharts + Vite

Готов к проверке
Проект полностью соответствует требованиям тестового задания Авито, включает всю необходимую функциональность и легко запускается.
